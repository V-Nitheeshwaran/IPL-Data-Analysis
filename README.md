# IPL Data Analysis Project

## Overview
This project analyzes IPL cricket data using Python, Pandas, and Matplotlib.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Top Winning Teams
- Toss Impact Analysis
- Top Run Scorers
- Player Performance Analysis

## Dataset
Dataset taken from Kaggle IPL Dataset.

- IPL_Analysis.ipynb
